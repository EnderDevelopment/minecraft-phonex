# PhoneX

PhoneX is a Minecraft plugin that enhances the gameplay experience by introducing a virtual phone system with calling capabilities and an app store. Players can use the phone interface to make calls and access various applications, including Twitter, directly within the game. The plugin is designed to be user-friendly and integrates seamlessly with the Minecraft environment.

## Install

1. Download the PhoneX plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Join the Minecraft server where the PhoneX plugin is installed.
2. Use the command `/phone` to open the phone interface.
3. Use the phone interface to make calls by entering the recipient's number.
4. Open the app store by selecting the app store option in the phone interface.
5. Install and launch apps like Twitter from the app store.
